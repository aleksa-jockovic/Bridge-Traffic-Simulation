# Bridge Traffic Simulation

A C# Windows Forms application that simulates the movement of cars and trucks across a bridge with a limited weight capacity.

Developed as a collaborative high school programming project, the application demonstrates object-oriented programming, vehicle movement logic, and basic resource management.

## Features

- Graphical representation of a bridge, cars, and trucks
- Vehicle movement across the bridge
- Different vehicle weights
- Maximum bridge load capacity
- Weight validation before vehicles enter the bridge
- Dynamic traffic flow based on available bridge capacity

## Technologies

- C#
- Windows Forms
- .NET

## Implementation

The application uses classes to represent vehicles and manage their movement across the bridge.

Vehicle movement and admission logic determine whether an additional car or truck can enter without exceeding the bridge's maximum weight capacity.
